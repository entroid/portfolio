# Hernán Ainsa — Portfolio

Personal portfolio, rebuilt from a static Webflow site into a Next.js
project. Design engineer's portfolio _and_ a demonstration of how it was
built — see [`docs/`](docs/) for the full technical documentation.

> 🚧 In progress. This README will be filled in properly (live link,
> screenshots, stack badges) in the final implementation phase — see
> [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md) Phase 13.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · react-three-fiber ·
Motion · next-intl · Vitest + React Testing Library · FormSubmit

Full rationale for every choice: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

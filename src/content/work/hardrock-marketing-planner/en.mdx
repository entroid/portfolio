## Approach

Reverse-engineered the legacy Excel/SQL logic into a clear, scalable data hierarchy: Plan → Jobs → Campaigns → Offers/Tiers. That standardized how campaigns are created, managed, and reused to speed up the process and keep consistency. Mapped and validated the core flow (create plan → add jobs via import/copy/create → define campaigns and offers → validate and publish to CMP or export) with a FigJam flowchart before touching UI, then built wireframes and HiFi prototypes on top of that model.

In parallel, treated the design system as a product decision, not just a styling exercise: built it on Ant Design as a foundation, then defined tokens (color, spacing, typography) as the shared source of truth between Figma and code. So FE consumed the same variables design was iterating on. To close the loop with development, set up an AI-assisted workflow (Figma MCP → React) that generated ui/component code directly from Figma into a separate branch, which developers then reviewed and merged — turning handoff into a working starting point for engineering rather than a static spec to re-interpret.

## Key Product Decisions

**• Simplified the system structure.** standardized an unstructured, scattered business-rule-heavy process into a clear hierarchy, despite initial stakeholders resistance to change — trading short-term friction for long-term consistency and scalability.

**• Protected usability in data-dense views:** Reduced visual noise by limiting displayed data (dozens of overlapping campaigns with thousands of offers per month) — layering detail behind interaction and creating a color-based system to communicate extra information, prioritizing clarity over cognitive overload.

**• Automated repetitive workflows at interaction level:** designed job import and duplication workflows, data autofills, quick approvals and direct publishing, reducing manual effort and human errors.

## Technical notes

- **• Base component library:** the interface was built on **Ant Design** as the base component library, which kept the team from re-solving already-solved interaction patterns (tables, date pickers, form validation, pagination) and focused engineering effort on the app's actual complexity — the campaign data model and calendar density — instead of UI plumbing.

- **• Design tokens as the design-dev contract:** color, spacing, typography, and component variants were defined as tokens on top of Ant Design's theming layer (through **Tailwind**) rather than hard-coded values, so changes propagated from a single source of truth shared between Figma and the codebase.

- **• AI-assisted Figma-to-code pipeline:** component code was generated directly from Figma files via **Figma MCP** into a dedicated branch; developers reviewed, adjusted, and merged from there, so the handoff produced working React components instead of a static reference to rebuild from scratch — cutting implementation time on the design system layer.

## Results

Early MVP feedback showed marketing teams replacing manual workflows with the new system, creating campaigns faster, with fewer errors, and at a significantly higher scale. The core lesson: the biggest impact came not from adding features, but from structuring complexity and enabling automation.

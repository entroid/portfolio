## Proceso

Arrancamos desde cero, con talleres junto a stakeholders y futuros usuarios para entender necesidades de negocio y los pain points del proceso actual. A partir de ahí organizamos user journeys básicos y los requerimientos principales de features, seguido de las primeras versiones de arquitectura de la información, relaciones entre features y user flows — todo mapeado colaborativamente en Mural. El ritmo del proyecto era rápido, así que priorizamos iterar ideas, presentar y testear hipótesis rápido antes de pulir.

## Decisiones Clave

**• Acotamos el POC a 3 features core** (Impact Comparison Tool, Prioritization Matrix, Data Input Flow), dejando dashboard, analytics y gestión de usuarios para una fase futura — control de alcance necesario para un proyecto de ritmo rápido.

**• Definimos 4 roles de usuario desde el inicio** (Decision Makers, Project Owners, Analysts/Contributors, Admin Users), lo que moldeó las decisiones de permisos y de flujo desde el diseño temprano, no como ajuste posterior.

**• Reemplazamos la comparación estática de spreadsheets por un modelo visual de datos** — un gráfico de burbujas que compara proyectos por costo, esfuerzo e impacto estratégico — atacando directamente el problema raíz: la pérdida de claridad estratégica en Excel.

## Notas

- **• Síntesis colaborativa en Mural:** entrevistas y talleres con stakeholders se tradujeron en arquitectura de la información, brainmaps y user journeys de forma visual y compartida, antes de tocar wireframes.

- **• Wireframes como herramienta de exploración, no de aprobación:** se usaron para explorar layout y flujos de carga de datos, con sesiones de validación frecuentes junto a stakeholders y usuarios potenciales — iterando rápido en vez de llegar con una propuesta cerrada.

- **• Multi-tenant desde el diseño:** "My Workspaces" contempló múltiples clientes/organizaciones (con posibilidad de espacios deshabilitados) como parte del modelo de datos desde etapas tempranas, anticipando el uso del producto como servicio para terceros.

## Resultados

El feedback temprano del MVP mostró decisiones más rápidas, alineadas y basadas en datos. Los stakeholders pidieron features adicionales para la siguiente fase — señal de fuerte engagement y valor percibido, no solo cumplimiento del alcance inicial.

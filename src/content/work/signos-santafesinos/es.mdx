El proyecto presentaba tres libros históricos, cada uno con su propia
sección: "Florian Paucke — Hacia allá y para acá", que recopila el trabajo
de un misionero jesuita del siglo XVIII entre el pueblo mocoví; "Santa Fe
entre dos siglos", una galería de fotografías entre 1860 y 1910; y "Signos
Santafesinos en el Bicentenario", un recorrido temporal por hitos clave de
la provincia, con línea de tiempo y más contenido textual que las otras dos
secciones. El trabajo vino con restricciones concretas: burocracia estatal,
normas estrictas de uso de imagen (resolución completa, sin ningún tipo de
retoque), un plazo ajustado atado a la fecha de presentación de los libros,
y un pedido explícito de diseño ultraminimalista para que las imágenes
fueran las protagonistas absolutas. Construí el sitio como frontend puro
(sin base de datos), con HTML, CSS y jQuery + Bootstrap, con el contenido
de texto e imágenes de cada pantalla manejado vía JSON.

El desafío acá no fue de complejidad de interacción, sino de restricción:
pocas herramientas, poco tiempo, reglas estrictas de uso de imagen, y la
responsabilidad de resolver todo el ciclo — discovery, diseño, código y
deploy — en solitario.

## Resultados

El sitio se entregó a tiempo para la presentación oficial de la trilogía,
cumpliendo con las normas de uso de imagen exigidas por el gobierno
provincial.
